# 自录视频授权与采集检查表

> 这是项目执行清单，不替代适用地区的正式肖像权、隐私或版权法律文件。

## 录制前

- [ ] 设备所有者同意拍摄和科研/产品使用；
- [ ] 出镜人员知道视频可能用于论文、模型训练和产品演示；
- [ ] 已确认是否允许公开原视频、短片段、关键帧和标注；
- [ ] 画面中没有住址、快递单、Wi-Fi密码、序列号或无关个人资料；
- [ ] 背景没有受版权保护的音乐、电视节目或电脑内容；
- [ ] 涉及电钻、压力锅等风险设备时，由有经验人员操作并遵守说明书；
- [ ] 产品型号和对应手册版本已记录。

## 录制内容

- [ ] 正常完整操作；
- [ ] 维护或清洁；
- [ ] 至少一种可安全复现的错误或异常；
- [ ] 操作面板、部件和状态灯特写；
- [ ] 固定机位和第一视角至少选择一种；
- [ ] 保留原始音频，不添加商业背景音乐；
- [ ] 每个步骤前后保留1–2秒稳定画面。

## 录制后

- [ ] 生成不可变 `video_id` 和 SHA-256；
- [ ] 保存设备类别、品牌、型号、拍摄者和日期；
- [ ] 授权文件与视频ID关联，但不放入公开 Git；
- [ ] 删除GPS、设备序列号等无关元数据；
- [ ] 指定 train/dev/test，独立测试素材不得进入训练；
- [ ] 三名标注者看到的是同一份冻结文件。
