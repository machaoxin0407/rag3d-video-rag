# 视频检索与 API 集成基线（2026-07-19）

## 产品结果

现有 `/chat` 技术问答现在可以同时返回：

1. 原有手册文本答案；
2. 原有 `<PIC>` 手册图片锚点；
3. 最多 3 个相关视频场景，包括起止时间、MP4、关键帧和 ASR/OCR 证据文本。

客服问题保持原行为，`videos` 返回空数组。视频检索失败时仅降级为手册答案，不影响原问答链路。

## 检索基线

- 检索单元：25 个 `video_scene`；
- 索引：内存 BM25；
- 文本：产品类别、中文/英文产品别名、场景 ASR、去重后的 OCR；
- 产品约束：查询中明确出现产品别名时，只保留对应产品类别；
- 多样性：每个源视频最多返回 2 个场景；
- API 上限：每次最多返回 3 个场景；
- API 证据文本最长 1,000 字符，完整内容仍保存在 manifest。

这一实现不依赖在线 embedding 或 rerank 服务，可在 API 进程内毫秒级加载和查询，适合作为可部署的第一版以及论文中的 lexical baseline。

## 服务器验收

`validate_video_retrieval.py` 在服务器完成以下 6 类查询：

| 查询 | 期望类别 | 结果 |
|---|---|---|
| 如何使用咖啡机制作 espresso？ | Espresso Machine | 3 个场景，类别全部正确 |
| How does a CCD digital camera work? | Camera | 2 个场景，类别全部正确 |
| 洗衣机脱水时是什么状态？ | Washing Machine | 3 个场景，类别全部正确 |
| 怎么使用吸尘器？ | Vacuum | 2 个场景，类别全部正确 |
| 压力锅工作时是什么样？ | Pressure Cooker | 1 个场景，类别正确 |
| 打印机如何打印页面？ | Printer | 1 个场景，类别正确 |

附加验收：

- “订单什么时候发货？”没有返回视频；
- `/chat` 合约测试返回 HTTP 200，并保留视频数组；
- 带 Bearer Token 的 MP4 请求返回 HTTP 200 和视频媒体类型；
- `../.env` 目录穿越请求被拒绝；
- 媒体端点只允许 `data_video/processed/` 下的 MP4 和 `data_video/keyframes/` 下的 JPG。

合约测试用固定假回答替代外部 LLM，只隔离验证本阶段新增的视频检索、响应序列化和媒体服务；没有把外部模型可用性混入本地视频检索结论。

## 当前限制

- 该版本是词法检索，跨语言能力依赖显式产品别名；
- 5 个纯视觉场景没有 ASR/OCR 文本，只能按产品类别召回；
- 尚未使用视频向量、VLM caption 或跨模态 rerank；
- 当前 6 个查询用于工程冒烟，不是论文统计测试集；
- 公开视频与现有手册产品并非完整一一对应，不能把当前命中率作为最终论文指标。

## 下一步

1. 对 25 个场景生成 VLM caption，补齐 5 个空文本场景；
2. 构建至少 100 条人工查询和场景相关性标注；
3. 对比 BM25、dense、ASR-only、OCR-only、caption-only 和融合检索；
4. 评估 Recall@K、MRR、nDCG、时间 IoU、媒体返回延迟；
5. 将视频结果与手册段落联合重排，形成论文的主要方法和消融实验。
