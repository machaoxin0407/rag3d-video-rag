# 无自有实物条件下的独立测试数据获取方案

## 1. 当前约束

团队 A/B/C 均没有可直接录制的目标产品。公开视频可以支持训练和开发，但仅靠随机切分公开视频不足以证明对真实用户上传视频的泛化能力。

## 2. 双测试集设计

### 2.1 开放来源隔离测试集

- 从最终接受的开放许可视频中预留20%；
- 按作者、频道、原始视频和拍摄场景隔离，而不是按片段随机切分；
- 冻结前生成视频ID清单和 SHA-256；
- 冻结后不再用于提示词、规则、阈值或模型选择；
- 用于可复现的主实验。

### 2.2 委托录制 OOD 测试集

- 优先联系产品维修店、设备实验室、创客空间、摄影社群和拥有设备的独立创作者；
- 录制者不得提供训练集视频；
- 每个保留产品类别目标5–10条，总计40–80条；
- 每类至少覆盖正常操作、维护和一种安全可复现异常；
- 使用统一任务书，但不提供模型答案或精确时间边界；
- 必须允许科研评测、商业产品内部验证、论文展示必要关键帧/短片段；
- 是否允许公开原视频单独约定，默认只发布URL/ID、标注和统计。

## 3. 录制任务书

每条视频建议2–5分钟，要求：

1. 展示产品整体、型号和关键部件；
2. 完成一个从开始到结束的 procedure；
3. 拍摄操作面板、手部动作和状态变化；
4. 原始音频保留，不添加背景音乐；
5. 不展示地址、账户、Wi-Fi密码、设备序列号和无关人员；
6. 至少1080p、25fps，镜头稳定；
7. 每个步骤前后保留1–2秒稳定画面；
8. 风险设备严格遵循说明书，不人为制造危险故障。

## 4. 人员职责

- A：维护委托清单、核验授权范围、保存书面证据；
- B：检查视频质量、产品匹配、隐私和任务覆盖；
- C：冻结测试集、组织双人标注并裁决分歧；
- Codex：搜索候选创作者、生成联系文本、检查清单一致性和构建数据管线。

## 5. 阶段验收

最低可启动第二周工程开发的条件：

- 至少5类产品各有15条开放许可候选；
- A/B/C 完成首批视频双重审核；
- 至少联系10名独立创作者或机构；
- 至少2名创作者明确愿意按任务书录制；
- 测试集授权至少覆盖科研评测和论文展示；
- 费用和外部联系由项目负责人批准后再实际承诺。

若两周内仍无委托录制来源，先以开放来源隔离测试完成产品原型，并在论文中把缺少真实用户 OOD 测试列为限制。
